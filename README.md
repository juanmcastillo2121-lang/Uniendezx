# Juego Matemático – Math Challenge

¡Pon a prueba tus habilidades matemáticas con **Math Challenge**! 🧠

Math Challenge es un juego matemático diseñado para mejorar la agilidad mental y poner a prueba tus conocimientos en las operaciones básicas: **suma, resta, multiplicación y división**.

El juego consiste en resolver operaciones matemáticas contra el tiempo, intentando conseguir la mayor cantidad de respuestas correctas antes de perder las tres vidas disponibles.

## Características principales

* ➕ **Suma:** Resuelve operaciones de adición.
* ➖ **Resta:** Pon a prueba tu capacidad de cálculo.
* ✖️ **Multiplicación:** Demuestra tu rapidez multiplicando.
* ➗ **División:** Resuelve divisiones correctamente.
* ⏱️ **Tiempo limitado:** Responde antes de que se agote el tiempo.
* ❤️ **Sistema de vidas:** Tienes 3 vidas para completar el desafío.
* **Tres modos de dificultad:** Elige el nivel que mejor se adapte a tus habilidades.

## Modos de juego

El juego cuenta con tres niveles de dificultad:

| Modo       | Descripción                                                                 |
| ---------- | --------------------------------------------------------------------------- |
| 🟢 Fácil   | Operaciones sencillas para quienes están comenzando.                        |
| 🟡 Normal  | Operaciones de dificultad intermedia para poner a prueba tus conocimientos. |
| 🔴 Difícil | Operaciones más complejas que requieren rapidez y concentración.            |

## ❤️ Sistema de vidas

* El jugador comienza con **3 vidas**.
* Cada respuesta incorrecta representa una pérdida de vida.
* Si las vidas llegan a 0, termina la partida.
* ¡Intenta conseguir la mayor puntuación posible sin perder tus vidas!

## ⏱️ Sistema de tiempo

Cada desafío debe resolverse antes de que termine el tiempo disponible.

¡Piensa rápido, responde correctamente y demuestra tu habilidad matemática!

## Objetivo del juego

El objetivo principal es resolver la mayor cantidad de operaciones matemáticas correctamente, evitando perder las tres vidas y controlando el tiempo disponible.
